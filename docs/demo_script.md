# Product demonstration

1. Open Overview. Establish that every count comes from persisted API records. Open Knowledge base and inspect the Request body source, revision and timestamp.
2. Create a synthetic ticket describing a FastAPI POST receiving an invalid JSON field. Record the actual request shape if known. Leave dependency versions empty to surface the diagnostic gap.
3. Open Investigations and run analysis. Point out the suggested category, priority rule, missing details, and the distinction between a possible explanation and a verified cause.
4. Expand a cited source, read its quotation and open the official page. Compare it with all retrieved evidence, including chunks the model left unused. Explain why source membership alone cannot prove the diagnosis.
5. Edit the customer reply, choose a decision and refresh. Show the saved edit alongside the original analysis. Record one reviewer assessment.
6. Submit an unrelated gardening question. Inspect whether the provider abstained and whether its reason is justified. An unsupported proposal is a model failure to record.
7. Open Evaluation with the administrator key. Show corpus revisions, per-query rankings, document-level metrics and the small dataset size. Close by describing one failure that a larger held-out test set could reveal.
